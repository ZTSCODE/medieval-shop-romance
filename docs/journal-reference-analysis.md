## 人物关系

参考的构图由左侧肖像目录与右侧人物记录组成，**没有贯穿纸面的竖分隔线**。参考大肖像左边约在纸宽31%，上边约在纸高16%；姓名在右上，花与缎带在姓名下方，细线靠近肖像底部。相遇标题紧接肖像组，地点和描述再往下，底部小花与未说完的话形成低权重收尾。

本轮对应修改：去掉竖线；150像素肖像目录、230×245主肖像、48像素姓名；重绘三朵蓝花与厚缎带并收敛色彩；好感保留为小字，统计移入头像提示；加入地点行、分隔线、底部记录提示与左边细绳。人物关系标题直接嵌入主纸顶部，两枚真实页面标签露在纸后。

## 配方

参考的左侧列表约占纸宽三成，有“已发现”标题和短横线。每项是单独的亮纸条；只有当前项有四角笔迹。右侧标题、原料和成品纸片、弧线箭头、下方说明形成四层。输入纸片小于成品纸片，留白用于分清输入与输出。标题是上方独立纸签，两侧有植物小印；右侧还有单独悬挂的旅途记录便签。

本轮对应修改：固定115像素原料片、138像素产物片，按真实原料数绘制细分叉箭头；数量为1只写名称，复用角色保留小字提示；选中四角断笔，移除整圈矩形框；配方页不套人物页的顶部标签。右上独立便签按可用空间显示，窄窗口不压右侧游戏入口。中英文长名称自动换行，避免扩大整个图解或拆出孤立的“口”字。

## 必须保留的内容差异

- 用户已明确保留现有主角和信使插画，所以角色画风不替换成概念图里的新人物。
- 实际只展示遇见的NPC和已发现配方；不会为了凑出参考中的三个头像、四项食物而编造内容。完整列表预览使用隔离测试进度，并在文件名标明fixture。
- 信使初次出现于森林，不能照抄概念图的“镇口”作为实际相遇地点。
- 用户要求仅保留左上关闭，概念图右上及底部的重复关闭不复现；没有功能的帮助按钮和第三分类页签也不伪装成可用。
- 弹窗仍覆盖当前牌桌，不把关系图的白天作坊或配方图的另一个夜景当作实际游戏地点。
