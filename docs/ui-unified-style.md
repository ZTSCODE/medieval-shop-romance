# UI共用样式约定

> 此文的分离纸边与460像素平铺规则已被用户于2026-09-22否决，保留作历史。最新完整纸面及独立缩放规则见 [ui-whole-paper-and-scale.md](ui-whole-paper-and-scale.md)。共用交互、字体与固定命中区域规则继续有效。

## 当前规则

所有常驻和浮动UI纸面通过 `paper_skin.gd` 绘制，颜色与纹理周期从 `ui_paper_palette.gd` 获取。禁止在各界面另乘一组临时底色，或重新引入旧整幅纸图。

| 同类对象 | 共用规则 |
| --- | --- |
| 暂停、设置、存读档、取名、确认、配方关系、序章对白 | 暗紫褐主纸，宽笔触，460逻辑像素周期 |
| 姓名签、标题签、小纸条、详情肖像承托 | 同一提亮纸层，不叠额外泛白磨损圈 |
| 输入与内嵌说明 | 同一压暗纸层，文字保持暖米白 |
| 普通操作、关闭、返回、下拉控件 | 普通纸色，悬停/焦点灰绿；按下不额外变暗 |
| 内容列表中的当前条目 | 赭红选中；悬停灰绿，按压独立处理 |
| 原主菜单/暂停长纸条 | 保留原长条叠纸轮廓，颜色从同一调色表取得；不拉伸成短按钮 |
| 小尺寸返回/保存等按钮 | 使用可拼接紧凑纸形；不能把长条图缩到文字容不下的高度 |
| 角色/地点卡牌 | 保留已确认的分类色与实际卡牌绘制；配方复用同一组件 |

新边沿使用 `unified_paper_20260922/brush-edge.png`，疏落的沿边笔触，禁止恢复碎污渍边、内沿渐变或多圈高频磨损。角色、场景内容插画和主菜单题板的印花属于内容美术，保留原身份与构图。

## 缩放

记录页整体缩放时，对纸纹周期、笔刷边宽与底纸偏移同步反向补偿；与其他窗口使用同样的最终逻辑像素密度。`paper_density_suite.gd` 对0.5/0.8/1.5三种比例的实际像素进行核对。外屏分辨率仍由原画布与显示设置统一处理。

通用控件图标由 `ui_icon_texture.gd` 返回逻辑尺寸，绘制时直接采样完整源图，不再预缩成18–28px位图。正文与标题统一使用 `forest_ui_typography.gd` 提供的宋体/衬线字体族。

## 交互

所有按钮遵循97%轻压、完整回弹、固定命中框。主菜单长条用独立视觉层；原生按钮用顶点绘制缩放；头像和叉号用绘制变换。按压不得再缩放实际Button节点。极快点放也完成轻压，隐藏时复位。入口打开后的选中状态不能把HUD入口永久染绿。

## 页面检查范围

主菜单、暂停、取名、设置、展开下拉、保存读取、覆盖确认、序章/对白、人物关系、配方、右侧HUD；检查中文/英文、720p/4K。记录完整列表的fixture仅作隔离测试，不写入真实玩家进度。
