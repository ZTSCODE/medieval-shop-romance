# UI细节返修对照

## 本轮基准

主菜单、暂停、人物关系、配方分别对照 `outputs/ui-smoke-brown-suite-20260919/01-main-menu.png`、`06-pause.png`、`04-relations.png`、`05-recipes.png`。对话采用用户后来确认的底部宽横纸与上方双人立绘，不恢复旧右侧窄栏。角色使用现有插画，配方显示真实已发现内容与实际卡牌，不为了填满参考构图添加假内容。场景地形与用户手摆植物不修改。

## 差异与改动

| 部位 | 发现的差异 | 本轮处理 |
| --- | --- | --- |
| 纸面 | 宽刷矩形明暗块占比大，像大片涂层 | 独立生成细密短弯干笔平铺纹理，低对比深褐；对话另做克制灰梅色调 |
| 窗框 | 同一灰色薄边，缺乏磨损与底层纸 | 透明独立纸边组件，固定角部、边条重复，原画的窄磨损、错层纸边，中心透明 |
| 菜单按钮 | 选中偏亮，纹理随长条比例显得稀疏 | 原PNG轮廓与alpha不变，叠细笔触，灰橄榄选中压低亮度 |
| 人物记录 | 列表头像无承托纸，详情肖像与故事纸没有边缘层次 | 小肖像底纸、列表窄纸边、全身肖像纸边、故事区域独立暗纸边 |
| 配方 | 列表项目只有红底与图案，边缘缺乏纸层 | 增加小图承托纸、窄纸边；继续直接复用TableCardView |
| 入口动效 | toggle和鼠标焦点导致永久绿色，未提供按压 | 只按当前悬停或键盘焦点着色；打开后恢复；97%轻压再回弹 |
| 头像 | 只执行聚焦和选中，没有视觉反馈 | 固定命中框，仅绘制内容做轻压，快速点放也播放完 |
| Esc叉 | 通用悬停放大与按压缩小互相争抢，命中边缘变化 | 禁用旧通用缩放，只缩绘制内容，按住/释放/移出/重开检查 |
