# 卡牌与对话纸片修订

## 本轮范围

- 依据用户本轮提供的《Book of Travels》截图，只重绘卡牌纸底、对话框及对话按钮；其余界面的美术等待用户确认后再调整。
- 纸面轻薄、平面、边缘基本平直，保留淡淡的手绘刷痕；不做厚度、卷边、立体倒角、破损轮廓或沉重阴影。
- 角色沿用现有透明立绘，卡牌纸底完整且不透明。图片只等比缩放或裁切，拖拽及打开动画也不能把图像压扁。
- 信使首次剧情自然读完后离场，主角与人物关系记录保留。用户确认暂不留下物品，不补设奖励或支线。

## 实施顺序

1. 分别生成三件独立纸片素材，归档提示词、来源与透明外缘范围，不引用旧 UI 作为外观参考。
2. 统一纹理等比显示，修复卡片底部漏空、头像变形与非等比弹性动画。
3. 将新纸片接入序章和人物交谈字幕；用淡入与轻位移保持轻盈感，移除对话框上的旧卷纸提示动画。
4. 用剧情后果配置执行一次性离场；保存结算状态，兼容旧存档，载入不重放事件。
5. 在 Godot 原生画面检查卡牌、对话、窄屏与宽屏，验证中途读档、结尾离场、重新进入游戏与暂停。

## 验收边界

- 渲染检查与逻辑测试通过不等于用户认可美术；提供实际游戏截图供用户确认。
- 不改变其他界面的美术素材，不新增掉落物，不打包，不覆盖真实玩家存档。
