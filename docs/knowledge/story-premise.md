# 剧情前提与文风（2026-10-03 用户指定）

> 本文件按时间记录用户每一次裁定的原话，前面的条目有不少已被后面的推翻。**整理后的现行设定在 `docs/story/bible/`**（世界观、地点、角色卡、文风、译名、剧情进度、待定问题），写文案时读那里；这里只在需要查某条裁定的来由时看。新增裁定时两处都要更新。

魔法中世纪，略带凯尔特神话风格。主角是被帝国通缉的成年男性，逃进森林后来到一座神秘小村庄，在那里经营卡牌商店。从《绝对魔权》(Absolum) 借鉴的是设定风格、叙事方式、氛围、结构、吸引点、异世感、命名方式和节奏，不照抄它的剧情。氛围是手绘幻想、有生活感的小店日常；男性角色恋爱，审美偏男同性向；感情克制、细腻、有潜台词，可以有隐约的性张力，禁止霸总腔和油腻调情，也不写裸体和床戏。开场流程：逃进森林 → 对话 → 第一张卡是一片森林 → 新手教程。

用户的工作要求：**故事内容直接用英文写，英文定稿后再翻成中文**；中文译名要有中世纪西方奇幻的感觉，不能用古风词（v0.2 的“总册、书吏、执达吏、无字林”已被否决）；不为主角硬造能力或奇特物品；名字不能像硬拼的。完整规则见 `docs/story/narrative-methodology.md`。当前提案（尚未确认）：`docs/story/world-bible.md`（世界设定集，开头的用户裁定优先）、`docs/story/opening-script-draft.md`（当前版本见文件标题）。

已确认（2026-10-03）：村名 **the Lee**（中文：背风地）；主角是被帝国追捕的普通人（最初设定为会合成的巫师，已于同日被用户推翻，见下文）；卡牌只是游戏的表现形式，故事里不解释，也不为它造词（**leaf** 被否决，原因是像生造的名词、为怪而怪）。文笔要像真正的文学作品，不能太口水，也不能为怪而怪；人文、文化等设定要先搭完整。已否决的方案：v0.1 的“司名 / 榛雾林 / 执灯人”，v0.2 的古风中文译名，v0.3 的 leaf / the Ledger。

2026-10-03 用户再纠正：去掉戒指（为一个奇特物品硬造的设定）。合成只是玩法，不是主角的剧情能力；主角是没有超能力的普通人，因为做了对抗帝国的事被通缉；统一叫“帝国”。罪名不能是古风话本式的（开仓放粮、伪造通行证之类被否决），要和凯尔特、西幻冒险气质相符；开场可以不说清，但要先设定好。现定：他小时候在林中迷路三天后走出，是唯一认得进林之路的人；帝国逼他给远征队带路，他在林边反水、烧掉地图，所以帝国要活捉他（见 world-bible.md §7）。

2026-10-03 用户再定：不必强调有块地帝国没染指，背风地就是白冬逃难过程中的普通村子，林子也是普通的；序幕写白冬和帝国借白冬对百姓的压迫，不牵扯其他国家，免得矛盾分化、戏剧张力不足。主角来历随之改为（待用户确认）：白冬时被帝国用一袋粮换走的孩子，被养成骑士；后来拒绝奉命烧一个藏种粮的村子，砍倒队长出逃，追他的四十个骑手就是他自己的队伍，帝国要活捉他当众吊死（world-bible.md §7）。

2026-10-03 用户定下世界主线（覆盖前面关于白冬的说法）：帝国的开创者借白冬把自由城镇一座座吞进地图，建立帝国；白冬至今仍在蔓延，为帝国效力；主角逃到帝国势力的边缘，因为找到了“对抗白冬的方法”的线索而被通缉。文风要像《绝对魔权》、《哈迪斯》、《指环王》那样的史诗西幻，不要古风；剧情先用英文写。用户要求和他沟通时也用英文。线索的具体内容（藏在地窖里、能在霜里发芽的旧城镇种粮）与主角身份（帝国骑士）是待确认的提案，见 world-bible.md §7。

2026-10-05 用户定下新的主线方向（覆盖上一段的“线索”与“帝国骑士”提案）：主角盗走的是**冬天里也能生长的种子**，游戏里他种这种种子，它是基础资源，所以种子本身不能带来任何坏处；背风地暂时还没被白冬波及。白冬在民间被拟人化，英文名用户定为 **the White Crone**（the Old Woman 太直白，已否决）；中文暂译“白老妇”，待用户确认。民间的说法：种子是她自己的粮食，所以能在雪里长；一百年前建立帝国的人去北方把它偷走，她追到南方来找，从此不走，这就是白冬；帝国借此带着面包收服城镇；后来种子流落到农户手里，帝国挨家挨户搜了一百年，因为谁把种子还给她，她就回家，帝国就完了。**这只是传说，真实情况没有人知道，不要另外编一套“真相”。** 实际发生的事：主角是帝国搜粮的兵，搜出了这种种子并上交（等于帮了帝国，那个村子被划掉、留给了雪），是有罪之身；之后他把种子偷出来逃了。用户否决的写法：“带着别处丢掉的春天”这类空话、根会发热、育种人与杂交留种（像写实的生物科研）、与冬天立约的三条款（复杂且不围绕主线）、给传说再配一个“真实的女人”。用户要的反转是往深处挖、万事因果相连，不是堆设定。

2026-10-06 用户对开头文字的两条意见：独白要有文学气质和语气词（喘息、叹气、说到一半的念头），平铺直叙的句子太干；**信使不知道主角在被通缉**，在他眼里主角只是个遇到困难、从雪里走出来的旅人，他也不追问。害怕身后有人的只有主角自己，场面里不出现能证实追兵的东西（狗叫、河边的灯、引开猎狗的围巾都已删去，改为信使留下水壶）。

2026-10-06 用户在文案审核器里逐句批注后定下的写法（两轮共 21 条，已全部改入游戏）：自言自语要像真人在那个处境下会说的话，多用带疑惑的自问（“马……应该钻不进去吧？”），不要下结论式的陈述，不要向不存在的人说话（“瞧”），不要像旁白一样描述过程（“越来越薄，然后就没了”），不要一本正经地报出名称（直接说“这灌木”，不说“是黑刺李吧”）；句子要有主语、标点要对；人物不能预先知道他不知道的事（分不清是灯还是月光时只能说“有光”，不知道林子里有没有人就不能说“住着什么”）；不要故作暗示的句子（“像是把什么事默默记下了”“你注意到了他没问”）；人和人之间用名字或称呼，不用职业泛称（烧炭人改为暂定名“老多纳尔 / old Donal”）。设定上：**白老妇是有侵略性、破坏性的**，不能用显得她虚弱的比喻（“懒得再涨的潮水”已删）；**去掉“背风地不问来处”这条村规**，信使只提醒一件事：别一个人进村。被整句删掉的两句（DLG_HERO_DOUBT_04、DLG_MESSENGER_EDGE_15）已不在剧情里，文案表里各留一个空行，只为让审核器能核对历史。
