# 当前音频方向

2026-10-06：用户要求按实际文案配声，尤其开头雪线附近的暴风、雪与脚下草丛/树枝变化，不能只按「森林、UI、BGM」泛泛分类。当前有效对白是 `story.messenger.edge` 与 `story.messenger.thorn_rules`；追逐段用暴露风声到遮蔽林地、有限动作和留白，危险被引开后才有很轻的暖色旋律。以对白真实动作和玩家实际探索为准，指令、往事和视觉比喻不直接制造音效；不重写故事。

集中事件目录和原句映射见 `docs/audio/README.md`。所有新增声音均为可替换 CC0 占位，原开场影片自身音轨保留。当前云端为 Dummy 音频设备，仅能做结构/波形/事件验证，主观听感需在可输出声音的设备确认。
