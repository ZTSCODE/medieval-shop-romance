# 卡牌题签接触阴影

题签阴影以用户提供的灰色题签参考为准：手绘接触暗痕，左右侧边延伸到题签上缘附近，并与底边连接，顶部留空；不能从侧边中段才开始，避免用户标注的左右空隙。不得使用喷枪式柔化光晕或连续均匀描边；也不能细到实际游戏尺寸看不见。当前笔触宽约 1.85–2.95 个卡片本地像素，颜料覆盖率约 0.32–0.70，粗细、深浅连续变化，避免碎成小方块。先画阴影再画纸张，内侧被纸张覆盖。按 get_title_rect() 当前范围定位，跟随卡牌缩放，绘制在插画上方；棋盘、配方共用同一实现，整条笔触合并一次绘制。[修改前后及实机原尺寸对比](../../outputs/card-title-connected-sides-20261006/index.html)，同目录 backup 保留上一版。验收必须同时看原尺寸与放大图。
