# 游戏悬停提示移除

按用户要求，游戏界面不再显示悬停提示。删除浮窗标题与关闭按钮、配方／关系入口与内容、玩家名字的原生 `tooltip_text` 赋值，并移除全局 `TooltipPanel`／`TooltipLabel` 皮肤；设置与时间控制入口由本轮对应界面修改一并移除。关系里程碑曾仅用于组装悬停文字的循环同步删除，既有关系数据、正文和必要错误提示保留。Godot 草地绘制插件的提示仅供开发编辑器使用，未删除。

搜索覆盖 `scripts`、`scenes` 及其他非资产源码中的 `tooltip`、`TipNote`、自定义提示回调，未发现其他游戏自定义提示来源；原设置分类的英文悬停断言改为确认提示为空。导入解析日志为 `outputs/settings-book-20260929/tooltip-removal-import.log`。新增界面不得重新依赖悬停文字呈现玩家必需的信息；图标的可访问性名称可保留。
