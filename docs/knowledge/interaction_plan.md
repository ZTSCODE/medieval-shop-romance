# 当前卡牌交互范围

用户已确认 Godot 4.7.1 的 2D 桌面，并在试玩后要求删除工具面板、禁止游戏撤销；随后明确添加 Esc 暂停主菜单、天数与当日进度。正常画面仅显示空白卡牌和窄的日进度显示，暂停菜单仅含继续/退出；不恢复新增、删除、整理、重置、摊开等工具入口。

保留左键拖动、从牌头拆出上半叠、整叠移动、吸附预览、鼠标缩放和平移。Esc 或失焦进入暂停，结束尚未提交的抓取；已经松手的操作没有历史回退。一天为 120 秒，暂停冻结卡牌与时间。规则数据与显示仍分开，正式经营、恋爱与美术不在当前范围。

验证应确认正常游戏没有工具按钮，暂停菜单仅有两个必要入口，Ctrl + Z / Ctrl + Y / Ctrl + Shift + Z 以及旧工具快捷键无效。检查计时冻结、继续和跨日；每次替换试玩程序后核对最终导出和运行截图。
