# 轻微透视的3D牌桌

用户明确授权将棋盘改为3D且只有少量透视。`TableStage3D`使用真正的透视Camera3D，FOV32、俯角72度（离正俯视18度），带厚边的32×22米棋盘，对应原3200×2200逻辑空间。牌桌场景在独立3D视口全屏绘制，右侧叙事栏和HUD继续使用屏幕UI。

卡牌规则、坐标和绘制接口保持原样：原world置于透明SubViewport，材质贴在真实3D牌面上；悬停和堆叠沿用原绘制，拖起时采用屏幕浮层，不宣称卡牌已成为独立刚体或每张都有物理厚度。镜头投影负责屏幕/世界坐标换算，拖放和产物飞行目标、组合进度及输出可见范围均按投影计算。滚轮缩放保留鼠标锚点，中键平移使用射线差值。阅读取景不写回存档镜头。

植被用`TableMeadow3D`和spatial材质，源场景细草/深灌丛/白花2200实例、分块MultiMeshInstance3D，真实受光和alpha裁切。草片根点位于原棋盘外380逻辑像素范围；为近俯视可读性，保持草片比例并将片面倾斜38度，根部仍固定，风动与鼠标拨动由显式elapsed驱动，Esc与阅读暂停时冻结。未改变源game工程。

验证：Godot原生流程48项、独立进程读档4项、投影/鼠标锚点/草甸/暂停尺寸变化16项通过；GameSnapshot121项通过，错误日志为空。存档版本仍为v5。运行时需要两个渲染视口；本轮验证仅代表当前本机正确运行，未做低配置性能承诺。原生截图及报告在outputs/perspective-review。新窗口标题为“卡牌小店 · 3D 棋盘”，便于区别仍打开的旧版。
