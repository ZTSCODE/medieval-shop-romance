# 植物投影与拿起卡牌

原植物批绘关闭cast_shadow，主光未启用阴影。现在植物使用双面alpha轮廓投影，暖色主光开启级联阴影。草片方向从主相机basis统一传入材质，阴影通道不再使用光源相机方向重新摆放草片。鼠标点光仍不开阴影，以限制额外开销。

拖卡原来卡面与阴影共同抬起，分离量很小。现在卡面提升22逻辑像素、放大4.5%，阴影留在桌面并向下偏移、扩散；放下恢复原大小和弹性落地。拖动仍使用屏幕浮层，不能称为独立物理卡牌。

原生输入测试确认主角可被拾取、进入拖动层、产生悬浮位移、放下回到牌桌且实际位置改变。若用户遇到仅特定卡牌或剧情阶段无法拿起，需按具体状态进一步复现；当前没有复现全局无法拖动。
