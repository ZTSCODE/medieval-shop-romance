# 标签软动效与设置退出

2026-09-29 用户澄清“不够 duang 软”专指标签：使用零初速阻尼弹簧，720ms 收尾，起落时轻压扁再舒展，纸面与图标共享变换且命中不动。下拉真实窗口从顶部展开 180ms，保持文字尺寸与原生命中；嵌入弹窗关闭时用一次实际画面读回作不接收输入的 120ms 顶部裁切收起，实测读回与裁剪约 2.0–2.3ms，不逐帧读回。首次展开补齐轻压反馈，高亮改暖灰底深字且边框为零。设置最终退出由 SessionOverlay 对纸页与遮罩共同父节点执行 200ms 退场，Esc 与返回按钮走同一路径。全游戏删除悬停提示，保留必要正文、校验错误与编辑器插件说明。
