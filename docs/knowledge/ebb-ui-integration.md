# B 版界面接入

## 用户批准

以 outputs/ui-directions-v4/01-ebb-witchhand-crayon.png 为布局基准；牌更长，人物立绘在对话栏左下，去掉紫色边框线。

## 实现

- 卡牌使用原112×184逻辑尺寸，避免存档位置迁移；独立生成中性色蜡笔边纹，固定角及等比重复边段。卡身不透明，角色和卡图等比裁切，内置深色标题栏，不恢复底部文字。
- 右侧35%为无描边暗蓝叙事栏。序章与对白共用字体/版式定义；长文本支持滚动，当前说话者取原立绘顶部60%进行等比显示，在栏左下落底。人物原图未修改。
- 正文暖白，继续操作暖金，姓名普通文本。旧粉色纸张与纸张舒展不再在这些界面运行；普通卡牌拖拽、倾斜、落地弹性仍保留。
- 主角头像、姓名、日期与日进度位于左下；配方、人物入口紧邻。蓝灰蜡笔背景单独生成并等比铺满，降低对比以突出卡牌。
- 阅读时根据可见卡牌范围调整显示取景，只操作世界节点呈现变换，不修改卡牌实际坐标或存档镜头。结束阅读恢复原镜头。
- 市场投卡区上移，给左下HUD和记录入口留出空间。其他系统窗口保留原主题。
