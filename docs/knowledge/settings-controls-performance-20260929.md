# 设置控件材质与长菜单

用户要求标签页和控件直接复用 Esc 菜单的纹理、阴影与立体感。`settings_control_paper.gd` 共用 `pause-button.png` 和三层克制接触阴影，固定边角、中间等比取景，按钮按下缩小绘制但不缩命中区域；返回直接使用 Esc 按钮组件。下拉最大高度限制为视口70%，在原生尺寸计算后解除内容强撑高度，关闭恢复测量；旧 `point * 0.66` 无上限 UV 曾使长菜单采到透明区露黑，已删除。真实生产路径40项菜单限高659像素，滚至末项39、再次打开、缩回3项、鼠标关闭复原均通过，底部截图为完整纸纹。

音量拖动旧链每一步同步写盘并全局 `apply_all`，现改只预览对应声道、松手一次提交，键盘250毫秒合并，退出及切页收尾，失败回退；60步旧链约580毫秒，新预览约0.26毫秒（回调耗时，不是整帧FPS）。自绘CanvasLayer在嵌入子窗口之下，`game_cursor.gd` 现自动追踪可见子窗口，期间使用同手绘纹理的原生鼠标，关闭恢复自绘，原生鼠标不包含在Godot视口截图中。
