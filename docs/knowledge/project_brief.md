# 项目简报

## 核心动力（2026-09-17 用户确认）

玩家的主要动力是**遇见 NPC、提升好感度、解锁剧情**。后续玩法策划以这条关系成长线为优先依据。经营、配方、货源与店铺成长如何服务角色相遇和剧情推进，需要围绕该目标设计；具体角色、好感规则、剧情门槛与分支尚未确认，不将策划建议自动视为已批准机制。

早期工程完成了基础卡牌交互、商店开关、固定买卖区、来客、耐心条、日周期和暂停等机制；2026-09-24 已移出旧实际内容。当前活动内容已接入开场独白及信使的两段对话，具体流程见 [开场运行记录](opening-story-runtime.md)，人物与待定关系设计见 [现行设定集](../story/bible/README.md)。已有对话不等于好感成长与恋爱路线已完成；下方初始范围只作历史背景。

**用户需求与当前范围：**制作中世纪背景的商店经营与成年 NPC 恋爱游戏，以非露骨的关系张力为方向；用户在历史对话中后续明确排除裸体和床戏，此边界优先于早期较宽泛的设想。历史表达涉及男性恋爱与骑士角色偏好，但具体角色阵容及路线尚未锁定。用户没有开发和上架游戏的经验，曾表达 Steam 非国区发行意向。2026-09-15 用户进一步要求类似 Stacklands / WitchHand 的玩法基础，并确认 Godot 4.7.1 的 2D 桌面方案；当时阶段只实现空白卡牌交互、基础界面与动画手感，经营和恋爱系统留待后续制作。现工程已采用 3D 场景配合 2D 卡牌与 UI，不能把初始 2D 方案当作当前实现说明。
