# 植被动态与鼠标暖光

本轮将草片改为相机平行面，着色器保持世界根点、相机基向量和朝向镜头的法线。取消原棋盘矩形discard，草叶可越过棋盘边缘；透明纹理自身的alpha裁剪仍保留。

交互采用16条带时间戳的扫动线段，计算根点到线段的最短距离。当前事件relative除以事件间隔换算世界速度，不依赖缓慢更新的velocity；速度从2至1200逻辑像素每秒平滑映射到0–1，并封顶。同向连续事件合并，取最强包络避免相互抵消或累加爆幅，保留阻尼回摆。

源工程只读参考`game/addons/grass_painter/grass_material.gdshader`：风强0.105、速度1.05、主波0.42/1.55、细波1.30/1.70、根部衰减1.75。meadow场景中关闭风的是树层，细草/灌丛/白花使用默认风。这里使用显式elapsed，暂停时风与拨动同样冻结。

鼠标通过牌桌射线定位一盏暖色OmniLight3D，离地1.7、半径4.5、强度1.2、不启用阴影；桌面改为受光粗糙材质，植物原材质受光，卡面仍保持原画色彩。光源不在叙事栏显示，暂停停止跟随。

卡底移除旧彩色边，内缩并削角匹配新卡框，避免分类底色露在外面。日轴保留上月下日，进度由上至下。

验证：风场12项、原生棋盘/透明底部/头像27项、鼠标光与日轴5项通过。原生像素比较确认桌面亮度增加；窗口截图和报告见`outputs/meadow-motion-review`。光效和摆幅仍可根据试玩反馈微调。
