# 缩放顿挫修正

2026-09-19：可见卡面区域与采样密度随镜头变化，旧实现也随之改变SubViewport.size，连续缩放时频繁销毁、分配GPU渲染目标。现在目标尺寸取物理3D视口的1.75倍、按256像素对齐、单边上限8192；缩放只更新采样映射，复用目标。窗口实际分辨率改变时允许重分配，卡面仍从源插画高清绘制。

相同2560×1440窗口、240帧放大后缩小测试：

|---|---:|---:|

| P95帧间隔 | 13.245ms | 6.679ms |

测试测量SceneTree帧间隔，包含本机调度与渲染影响，不是独立GPU计时或所有设备性能保证。证据保存在`work/zoom-before`和`work/zoom-after`。额外原生清晰度10项、紧凑棋盘/头像/底部交互27项均通过。保留纹理可能比远景按需尺寸占用更多显存。
