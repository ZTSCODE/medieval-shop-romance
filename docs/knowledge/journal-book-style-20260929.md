# 配方与人物关系书页

GameJournal 复用设置的 settings_book_paper、settings_book_tab 和 settings_book_skin，统一为 960×700 设计尺寸，正文区域 824×430；右侧入口保留，页顶新增配方和人物图标标签，标题随页切换。整页使用同设置的 0.72 秒阻尼回弹，关闭淡出，快速重开取消旧动画。缩放继续由 UiScale 统一管理。

JournalPanel 左侧列表宽 210，选中项提亮纸面并保留米白文字及细标识。配方保留真实卡牌预览，多材料换行滚动；人物采用完整头像、可滚动相遇记录和关系进度。条目动画绑定按钮寿命，刷新前停止旧动画。tests/journal_book_runtime_suite.gd 使用隔离模块和集中测试翻译验证，不写正式内容或玩家存档；预览中的配方、人物记录仅供检查布局。
