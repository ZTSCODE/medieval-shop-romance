# 设置页色调与动效

2026-09-29 用户要求保留 Esc 控件纹理，但色调匹配当前灰炭色设置纸页，标签同样调整；滑轨保留轻颗粒，两端圆头，菱形增加有透明余量的两层投影。设置控件色彩集中在 settings_control_paper.gd，独立于 Esc 菜单；返回按钮、下拉框和书签共用同一纹理与此色系。

交互采用短时克制动画：入场 200–240ms 淡入上浮，退出 120ms，标签 200ms 升起与换色，内容 160ms 加逐行 25ms 间隔，按钮 160ms 提亮并沿用 UiPressFeedback 的轻压回弹，开关下划线 180ms 平移。动画可中断重定向，隐藏时恢复；不修改音量拖动权威路径，不对滑块数值插值。专项检查快速切页、开关反向和隐藏重开，实机检查主菜单与暂停入口、下拉操作、保存和小屏布局；视觉仍由用户验收。
