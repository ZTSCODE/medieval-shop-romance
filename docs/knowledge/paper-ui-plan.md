# 纸质 UI 与新旅程流程重做

## 用户本轮要求

- 右下角统一显示主角头像、姓名、游戏时刻、天数与当日进度。
- 游戏启动进入主菜单；Esc 中“返回主菜单”先保存再返回，退出程序放主菜单。保留设置、读取、继续与新旅程。
- 新旅程先取名，再进入序章和教程；旧存档补名字不能清空进度。
- 卡牌变为更修长的比例，仅标题和近景大图。移除卡底说明与类别文字。
- 探索进度显示在整个组合牌叠上方，跟随牌叠、暂停冻结、拆开消失。
- UI 全部接独立生成的纸质美术资源，旧 UI 不作生成参考。纸页、按钮、页签、头像框、进度、滑块、勾选、关闭与各页面底板均列入资源清单。
- 保留原拖拽、存档、NPC 对话与经营兼容流程，不打包。

## 参考与视觉规则

已读取 ArtDirection.canvas 的 UI、视觉北极星及 Book of Travels 摘要，并实际查看官方《The Omnipresent UI》中的三张界面图。参考地址：

https://store.steampowered.com/news/posts/?appids=1152340&enddate=1602499527&feed=steam_community_announcements

采用浅象牙与灰米色手工草纸、自然纸边、细纤维、薄叠纸、灰绿/蓝灰墨迹和细笔符号，正文为深墨色。留白优先，装饰位于边角。参考图只用于视觉方法，不直接复制其文字、标志或布局；不参考现有项目 UI。

## 动画

窗口以轻微展开与落定呈现；按钮轻抬/压下，标签切换有纸页运动。另制作独立透明纸角动画，每张图只包含一帧。顺序严格为 00 与 08 → 04 → 02/06 → 01/03/05/07，相邻关键帧约束补帧。运行采用往返播放，避免首尾跳变；Esc 冻结游戏动效，系统窗口反馈继续。

## 验证

检查所有可见 UI 使用实际生成纹理；中文/英文及长姓名不溢出；右下角信息不被市场覆盖；新游戏/取消取名/旧档补名/返回菜单失败保护；瘦卡命中与合叠/产物来源动画；外置进度条位置与暂停；对话/记录/系统页切换；实际窗口、全屏和不同宽高比。最终提供游戏内截图和资源清单，视觉定稿由用户继续反馈。
