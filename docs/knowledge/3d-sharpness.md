# 3D 清晰度修正

2026-09-18：此前卡牌先按112×184逻辑像素绘入固定3200×2200纹理，再贴到3D平面放大；3D视口又按逻辑窗口尺寸渲染。实测2560×1440窗口只获得1600×900的3D画面，造成两次低分辨率放大。

现在3D视口按根视口的实际拉伸倍率分配像素，屏幕拾取与投影同步换算。卡面画布只捕获可见棋盘范围，按镜头缩放及屏幕像素密度重绘；3200×2200仍是逻辑世界尺寸，不再是固定纹理分辨率。捕获范围按64逻辑像素对齐，纹理单边最多8192，卡牌数据和存档坐标保持原样。

同一2560×1440测试场景中，修正后3D视口为2560×1440，可见卡面纹理为4608×2816。人物原图没有缩小，导入为无损且没有尺寸上限；无需重新生成美术。源插画仍使用线性过滤，只有最终已匹配屏幕像素的画面合成采用最近邻，避免再次模糊。

原生验证：清晰度/分辨率/拾取拖动10项、完整开场与对话流程48项、投影与植被16项，共74项通过，错误日志为空。修正前后同尺寸截图与报告在`outputs/sharpness-review`。高分屏近距离会增加显存和绘制开销，未作低配置性能承诺。

依据：[Godot Viewport.get_stretch_transform](https://docs.godotengine.org/en/stable/classes/class_viewport.html#class-viewport-method-get-stretch-transform)。
