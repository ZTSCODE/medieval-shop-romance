# 粉色纸张 UI 接入计划

## 已确认范围

2026-09-18 用户选择 `outputs/ui-exploration-v7/parchment-rose-aligned.png`。制作卡牌、序章/对话框、其姓名纸条与继续按钮；其余窗口沿用现状。以选定粉色、笔触、微破损边缘及略错开的底纸为准。

## 制作步骤

1. 单独生成不含文字的纸面平铺纹理、底纸纹理、组合纸边及纸条纸边，保存原图、提示词和来源记录。
2. 固定纸纹密度，固定角部与边框厚度；边缘通过重复组合适应长度。不同尺寸均检查接缝与透明边缘，纸面保持不透明，人物继续使用透明立绘。
3. 卡牌、横向对话纸各制作 9 张独立绘制帧。顺序为尾帧、首帧、中点、各区间中点；每帧同一画布和锚点。真实折面舒展，不以缩放、淡入、视频抽帧或程序插值替代。
4. 接入静态模块与逐帧播放器：首次显现播放，换句不重播，普通拖放不重播；Esc 冻结，读档恢复剧情而不重复结算。
5. Godot 原生运行检查中文/英文、窗口尺寸、纸张不透明、图片等比、实际动画、拖放/探索/信使离场和存读档。使用隔离测试存档，不打包。

## 验收区分

生成完成、透明/尺寸检查、运行检查与用户视觉接受分别记录。若动画与最终模块纸形存在衔接跳变，继续修正后再交付。
