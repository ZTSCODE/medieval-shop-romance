# 卡面简化与卡牌缩短

2026-10-04 用户要求卡牌不要过高、卡面不要过细或过暗。统一尺寸从 168×258 调整为 168×236，模型、显示、拖放范围继续共用 `TableState.CARD_SIZE`。回到已认可的十二张完整纸卡合集工作流，提取前六张插画，保留背景和角色上半身。用户否决随后过厚的纸边、过大的类型图标与生硬阴影：插画横向留边改为每侧 3.8%，人物图标宽为卡宽的 8.5%，植被图标单独按其透明留白适配；类型区采用短收尖斜向边界，不用矩形洞或宽模糊过渡。标题保持加高，但下缘阴影仅留低透明度短笔触。纸框、标题与拖放虚影共用九片绘制；色层 1.2%、亮度系数 0.985 保持。制作依据见 [制作文档](../art/card-face-generation.md)，[原图／错误版／修正版局部对比](../../outputs/card-proportion-correction-20261004/index.html)。
