## 透明度检查

`alpha-qc.json` 保存逐帧全图扫描结果，检查了主体连通区、主体外扩 2 像素后的残留、外侧 32 像素带、四角及指定空白位置，不只检查四角。

- 每张图都只有一个 alpha ≥ 16 的主体连通区。
- 纸外的棕色 RGB 出现在透明像素中。例如 04 的 `(100,768)`、`(512,30)`、`(150,768)`、`(190,768)` 均为 alpha 0，预览工具可能仍显示隐藏 RGB；实际合成按 alpha 判断。
- 主体外扩 2 像素后，00–07 的残留最大 alpha 为 3–4；08 最大为 5，仅三个像素达到 5；没有 alpha ≥ 16 的外部残留。

## 实际生成过程

请求顺序：08 → 08 透明度定向尝试 → 00 → 04 → 02、06 → 02 高度重绘 → 01 → 03 → 05 → 07 → 03 宽度重绘 → 05 宽度重绘。

02 和 06 在同一批请求中各自独立生成。共 13 次调用，采用 9 张：

- 08 透明度修正稿未采用：纸面 alpha 交给统一 renderer 处理，继续使用第一次终帧及其固定锚点。
- 02 初稿只有 1290 像素高，重绘后为 1354，避免中途明显变短。
- 03 初稿宽 653，超过后帧 629；重绘后为 617。
- 05 初稿宽 874，超过后帧 831；重绘后为 796。
- 其他最终帧均采用各自第一次输出。

所有九张归档图与对应原始输出 SHA-256 相同，未做裁切、缩放、拼合、改色、抠图或程序变形。未采用的原图保留在生成工具的原始路径，路径和哈希完整登记于 manifest。

内置工具没有暴露质量档、采样步数、种子或模型选择参数，本记录不声称使用了不存在的质量配置。没有使用 RTMPose 或 Wan。
