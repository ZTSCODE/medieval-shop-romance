# 右侧纵向入口

用户确认保留右侧时间轴，下方依次排列头像、姓名/天数、配方与关系按钮。统一中线为视口右侧62逻辑像素；底部预留纵排空间，时间轴自动缩短。头像保持点击聚焦，配方与关系继续打开原浮动窗口。

图标由内置imagegen分别生成，实际PNG含透明通道，保存于`assets/art/ui/ebb_crayon/recipe-icon-v2.png`与`relationship-icon-v2.png`。配方为打开的书与叶片，关系为双男性轮廓和小星。运行时按有效线条边界等比显示，不拉伸、不烘焙文字。悬停保留暖金反馈。

姓名改为头像下方居中，长名省略但提示保留全文；中英文短入口文案集中在game.csv。对白与序章继续按钮预留右侧列，头像层级置于叙事背景上方。

原生验证：1280×800、960×640、2560×1440的中线/间距/边界、两按钮打开窗口、头像聚焦及序章对白避让，共14项通过。截图在`outputs/right-hud-review`。
