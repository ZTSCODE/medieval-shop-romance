# 当前交互验收

- 正常画面只显示桌面、空白卡牌、当前天数及当日进度，无工具栏或侧栏。
- 完成移动/拆叠/合叠后，任何撤销或重做快捷键均不能改变状态。
- 新增、删除、整理、摊开、重置等工具功能没有按钮或快捷键入口。
- 拖动、拆出上半叠、整叠移动和吸附预览正常，卡牌身份与叠内顺序保持一致。
- 鼠标缩放与平移正常，原界面占据的空间可直接操作卡牌。
- Esc 打开或关闭暂停菜单，继续与退出按钮有效；失焦进入暂停，不能恢复更早的操作。
- 一天 120 秒，暂停时冻结卡牌、镜头、动效与时间，继续后保持剩余时长，跨日正确增加天数。
- 最终 Windows 程序通过实际窗口输入检查，并保留截图与导出记录。
