# 显示分辨率设置

窗口模式提供适合当前可用桌面的常见分辨率。选择后立即改变原生窗口客户区尺寸，并在独立设置文件保存`window_resolution`。旧设置缺省为`Vector2i.ZERO`，继续使用原有窗口几何恢复逻辑；显式选择优先于旧窗口尺寸。窗口拖动缩放后，选择器显示实际尺寸。

无边框全屏与独占全屏继续使用Godot原生全屏模式，覆盖当前显示器。分辨率栏显示显示器原生尺寸并禁用选择；窗口分辨率偏好保留，退出全屏时恢复。暂停不会阻止尺寸刷新，也不会推进游戏时间。音频改动不重复调整窗口。
