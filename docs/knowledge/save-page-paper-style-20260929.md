# 保存读取纸页

保存读取页复用设置页的灰炭色整纸、独立返回按钮、纸质按钮状态和软弹入场；四个存档槽以轻分隔线排列，避免旧圆角字段框与新纸面冲突。标题、状态提示、存档信息、保存与读取按钮共同缩放并参与入场；主菜单入口只读、自动槽不允许手动保存、手动槽隐藏规则、覆盖与读取确认以及实际存档验证路径保持原机制。确认窗口的面板和按钮也换为同色纸肤。

`tests/save_page_style_suite.gd --flow-qa` 使用输出目录中的独立存档验证真实鼠标保存／读取信号、只读与自动槽限制、返回和小屏等比布局；截图 `outputs/settings-book-20260929/save-page.png` 是独立运行验证，完整背景与遮罩退场由会话窗口统一承担。美术是否接受以用户游戏内检查为准。
