# 新手目标栏（2026-10-01）

用户要求在屏幕右上方加入新手目标栏，并于 2026-10-01 明确：位置在右侧**时间轴上方的空白区域**，不放在时间轴左侧。栏右缘与时间轴对齐、底边贴在时间轴上方；上方空间不足时按完整展开高度整体等比缩小。栏只在玩家能直接操作桌面时出现：主菜单、暂停、序章、对白、镜头过渡和手账打开时都会隐藏；首次出现前约停 0.9 秒，之后重新出现约停 0.2 秒。完成的目标打勾后，等栏重新显示时再补播动画。阶段完成时，标题右侧的金线月桂环会自下而上逐叶生长，顶端小星点亮，环中写“达成”；全部完成时环中写“出师”，随后栏向上淡出。2026-10-01 用户否决了红色圆形印章（太中式，不符合本作美术风格），也不要完成时窗框发光，两者都已移除。点击标题区可以折叠或展开。

目标定义在 `data/onboarding_goals.json`，按阶段排列，每个目标由“稳定 ID + 文案键 + 触发事件”组成；文案统一放在 `localization/game.csv` 的 `ONBOARD_*` 键中。目标进度只由 `scripts/model/onboarding_goals.gd` 判定，唯一入口是 `report(event)`。如果玩家提前做了后面阶段的动作，会先记为“已见”，进入该阶段时自动勾上；`debug_text()` 会输出带序号的因果记录。2026-10-01 用户确认：**每个存档的新手体验相同**。进度随存档保存在可选字段 `onboarding` 中，两种存档格式都支持，且不提升版本号。新旅程从头开始；读档恢复该存档自己的进度，已完成的目标直接显示为勾选；缺少这个字段的旧存档也从头开始。这个字段的数据如果损坏，只会让新手目标从头开始，不会导致整个存档读取失败。界面代码在 `scripts/ui/onboarding_goal_panel.gd`，它只读取模型状态。目前只覆盖已有机制：拖动桌面、缩放、点击头像、切换时间、翻开配方和查看人物关系。新内容（如买卖）可以在 JSON 中追加阶段，并在对应模块的权威路径中调用 `report`。验证方法：运行 `tests/onboarding_goals_suite.gd`（无界面）和 `tests/onboarding_goal_panel_capture.gd -- --flow-qa`，截图输出到 `outputs/onboarding-goals/`。
