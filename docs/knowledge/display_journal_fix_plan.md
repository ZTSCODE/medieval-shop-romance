# 分辨率与游戏内记录页修正

## 本轮要求

无边框和全屏适配玩家屏幕；配方、人物关系属于游戏内容，从 Esc 系统菜单移出。继续使用 Godot 工程运行，不打包。

## 实施

1. 实测窗口物理尺寸、游戏显示区域和缩放变换，定位全屏留边或布局范围固定的问题；调整为等比扩展可用画布，避免拉伸卡牌。
2. 在屏幕尺寸改变时立即刷新棋盘、客人、交易菜单和镜头布局。设置页暂停期间也响应布局变化，时间、耐心和动画进度保持冻结。
3. 增加独立的游戏内记录页，右上角提供配方、人物入口，保留 R/N 快捷键；记录页以浮层呈现，经营继续，页面注明这一行为。Esc 先收起记录页，再次按下才打开暂停菜单。
4. Esc 系统菜单保留继续、保存/读取、设置和退出；不挂载配方、人物页。记录页只拦截自己覆盖区域的输入，不能穿透抓牌、交易或缩放。
5. 更新项目约定、集中词条和操作说明；验证不同屏幕比例、原有拖拽、记录更新、暂停/读档与语言切换。

## 验收

实际窗口记录物理尺寸与可用画布，验证等比映射覆盖屏幕。16:9、16:10、21:9、4:3 分别检查布局；全屏额外匹配当前显示器尺寸。检查记录页与暂停菜单确实分离，记录页外可以继续操作，覆盖处不会误操作。
