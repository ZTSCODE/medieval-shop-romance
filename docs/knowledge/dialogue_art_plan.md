# 悬浮窗口、对话与首批美术

## 本轮结果

1. Esc、配方和人物关系使用有边框、可拖动的悬浮窗口，保留关闭、返回、存读档与暂停规则。
2. 序章保留牌桌背景与两张卡，以底部文字框显示四段文字；阅读时暂停时间和卡牌操作。
3. 玩家与信使新组合后打开双人立绘对话。对话期间冻结牌桌；Esc 可覆盖系统窗口，返回后继续原句。再次组合可重读简短问候，不反复增加好感。
4. 当前所有卡牌定义接入插画。提供的信使原图原样归档；主角与其他缺图卡生成临时美术。卡面和立绘共享同一角色来源。
5. 新增对话进度与已读记录存档，兼容以前的序章和经营存档。继续使用集中中英文本与稳定内容代号。

## 视觉依据

已读取用户指定三段美术历史及其实际图像、ArtDirection.canvas 的视觉北极星、UI 和 Hades 信息层级分组。角色按用户本次指定的硬边色块参考制作；UI 采用安静的深墨绿、暖纸色、细暗金边和少量暗红，不沿用参考角色的纹章或现成游戏 HUD。主角为成年男性旅人，清楚的肩背与面部结构、克制的亲近感；身份保持开放。

信使源文件的实际归档目录为 `.codex/generated_images`，与用户给出的旧目录不同。已确认源 PNG 为 994×1583、32 位 RGBA，四角 alpha 为 0。复制时保持源文件原样。

## 验证

- 悬浮窗口可移动且尺寸变化后仍在画面内；窗口上的操作不穿透至卡牌。
- 开场底部文字、双人立绘、两种语言在常用宽高比下可读。
- 双向拖拽组合只触发一次；持续叠放不会自动重复对话；重新组合可重读。
- 对话中保存、读取与 Esc 暂停，保留当前句和已读记录；旧存档仍通过校验。
- 图片实际透明度、引用完整性、Godot 导入和渲染分别验证；本轮不打包。
