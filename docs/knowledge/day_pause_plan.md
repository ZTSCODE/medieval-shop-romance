# 暂停与日进度

本次仅添加 Esc 暂停菜单与顶部天数/当日进度，不恢复此前删除的工具栏、侧栏或撤销/重做。暂停菜单提供继续游戏和退出游戏。按 Esc 打开或关闭；打开时结束尚未完成的抓取，冻结桌面、动效和游戏时间。失去窗口焦点时进入暂停，返回窗口后由玩家继续。

用户已确认每天 120 秒、自动进入下一天，天数从第 1 天开始。时长独立配置，不写进卡牌规则。天数与进度由一个独立计时节点维护，界面只读取；暂停期间不能推进，跨日只增加一次对应天数且保留超出的时间。后续经营结算尚未制作，本次也不接入存盘。

验证重点为 Esc 的开关和按键重复、拖牌过程中暂停、菜单阻止穿透操作、继续后的输入恢复、实际时间冻结、跨日/连续跨日，以及禁止撤销的既有约束。截图分别检查正常桌面与暂停菜单，再导出 Windows 程序复测。
