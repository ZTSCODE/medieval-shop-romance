## 制作分工与顺序

1. 归档参考、备份当前源与素材。
2. 独立生成地面可平铺材质、纸纹、纸边、植物、前景道具和远景建筑组件；不生成一张包含所有内容的运行时图片。
3. 制作固定尺寸角部/平铺边线/独立中心纹理的纸张绘制器。文字保持运行时字体和本地化；图标与插画等比采样。
4. 林地重构为近中远层次，牌桌边缘用独立组件，交互植物沿真实棋盘边界分布。
5. 卡牌、侧栏、双人对话接入同一组纸张组件；配方和人物记录改为左选择、右详情。
6. 检查4K与普通分辨率、缩放后的清晰度、平铺接缝、卡牌遮挡、窗口布局、拖放与完整剧情流程。保留真实运行截图与报告。

## 验收边界

参考图确定构图、材质、色彩与信息层级；保留用户指定的现有角色插画和已实现玩法。不得把示意图里的新角色、配方或情节擅自加入实际进度。生成图实际尺寸如实记录，禁止以放大像素宣称原生4K资源；用可平铺/可组合部件满足4K显示密度。
