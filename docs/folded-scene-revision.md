# 折面场景与界面返修

## 最新修正

菜单使用棋盘概览的相机高度、朝向及32度视场，只将取景中心向棋盘上方平移；不会沿后坡推进至城镇。棋盘与60度后坡之间加入1.6米长的30度倒角段，三段共用同一网格与连续展开UV。鼠标射线分别求交三段，取最近有效交点；植物根点仍经同一映射。选中金箔换为克制的哑光浅暖金组件，保留小范围不规则露底。

## 用户纠正

上一版屏幕叠层远景、过大的卡牌以及普通表单式记录页未达到参考。此次以真实空间关系和独立美术组件重做，保留原人物插画、唯一离场事件和存档功能。

## 实际结构

- `FoldedTerrain.make_mesh`在同一个ArrayMesh中生成棋盘及外围地面；后缘向下折60度，逐渐远离现有72度俯视的摄像机。UV保持展开地面米制坐标，折面不拉长纹理。
- 近植物、后坡树团与城镇都位于折面真实坐标。远景云层/树林位于固定远距离QuadMesh，保持原图3:1比例，取消屏幕horizon遮罩。
- 卡牌拾取仍射线到棋盘平面；植物拨动射线对折面求交并还原展开坐标。
- 卡尺寸168×258；v7旧档以448×688验证，再迁移v8。早期各版尺寸仍分别验证。新档越界不自动修补。
- 专用卡纸、金色外线、顶部签条、主菜单题板和按钮、记录花枝与缎带均独立PNG组件。主菜单为独立三维场景，天空、远镇、路径、树、桌面和道具分别放置；UI文字保持本地化资源。

## 检查方式

`folded_scene_runtime_suite.gd`留概览及放大上沿截图，检查同一网格、无屏幕叠层、后坡深度递增及射线回算。`card_geometry_v8_suite.gd`检查旧尺寸严格校验。`forest_rebuild_runtime_suite.gd`覆盖4K主菜单/记录/对话/暂停与720p完整离场流程。视觉效果以实际截图对照参考，不把结构测试视为美术相同的证据。
