# 立绘

沿用已确认的精致人物插画风格与角色身份，完整人物、真实透明 alpha，不套用卡面画法。变体可输入对应角色立绘；不预裁切、不拉伸。参考：[主角](../../assets/art/opening/hero.png)、[信使](../../assets/art/opening/messenger.png)。[生成模板](portrait-style/prompts/portrait-template.txt) 为后续指导，非历史原提示词。

仅供对话及关系右侧，使用 `portrait_path` / `GameArt.portrait`；卡面用途见 [卡面规则](card-face-generation.md)。对话保留双人立绘及说话者动画、置顶；关系右侧完整显示人物。替换立绘不影响卡面。
