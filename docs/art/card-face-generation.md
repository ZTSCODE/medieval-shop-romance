# 卡面

沿用用户认可的[来源对话](codex://threads/01a10445-e0dc-7773-9ca3-f68305e3266d)完整纸卡合集工作流，内置 imagegen 一次生成十二张小纸卡，再提取插画接入，避免单幅大画的细碎刻画。当前复用成功工作流的[原 UI 参考](../../outputs/card-soft-short-20261004/reference.png)与[实际提示词](../../outputs/card-soft-short-20261004/prompt.txt)，角色上半身、完整绘制背景、较亮色值。立绘与被否决的卡面不作为输入。

前六张插画接入 `assets/art/cards/painted_20261004/`；其余为合集样例，不新增游戏内容。运行时卡框、类型标志和本地化标题独立保留，同套卡面用于棋盘、配方、关系左侧和主角头像；对话及关系右侧继续用原立绘。当前原生切分 210×294，插画等比裁切；卡牌尺寸 168×236，比原长版缩短约 9%。卡纸共用带轻微起伏的圆弧四角轮廓，标题九片绘制适配宽高；左右留边收窄为每侧 3.8%，人物类型标志宽 8.5%，保留加高的标题。左上承载标志的纸面单独按原参考边界采样，略有起伏、底部短收边，没有矩形洞或直线斜切；要求调整区域轮廓时不得连带替换图标。统一色层 1.2%，亮度系数 0.985，轻微暗于明亮重绘版，仍亮于被否决的暮色版。[区域轮廓最新对比](../../outputs/card-type-shape-20261004/index.html)。 [圆弧四角实机对比](../../outputs/card-rounded-corners-20261004/index.html)。
