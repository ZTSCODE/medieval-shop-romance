## 像素对照

1. 在参考分辨率对齐每个组件。候选图仅按整体等比容纳，禁止靠改颜色、直方图匹配、非线性变形把差异藏掉。
2. 对动态文字/原有角色/真实卡牌插画预先登记排除区。不能看到失败后再增加遮罩；轮廓、纸边、静态图标、纸面保留在比较内。
3. 量化预筛：RGB平均绝对误差≤8/255，95分位误差≤24/255，8×8局部SSIM平均≥0.90。预筛通过也不自动通过美术。
4. 同时查看原图/候选/差异热图，逐项检查轮廓、叠层方向、边厚、笔触尺度、色差。手工轮廓与图层检查必须有明确结论；未检查默认pending。
5. 整体布局在参考坐标系内误差≤2像素；4K与1080p截图不得出现接缝、边缘扭曲、低分局部放大、文字裁切或遮挡。
6. 数值失败、原图区域不可分辨、手工检查未完成均为不通过/待核对，不能改阈值凑通过，不能拿功能测试抵扣。生成器返回低分辨率不能称为4K资产。
