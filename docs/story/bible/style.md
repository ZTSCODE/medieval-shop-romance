# 文风（现行）

**总的标准【已定】** 每一句都要经得起两个问题：这是不是文学上好的句子；这个人在这个处境下会不会对这个人这么说。要有文学气质，不能口水，也不能为怪而怪或故弄玄虚。用户在批注里给的信息是**人物和世界的设定，不是台词**：设定体现在人物怎么做、哪些话不说上，不要让人物把设定说出来。场面要有呼吸：走一段路、停一下、一个具体的东西，胜过一句说明。不要为了把信息交代完而写一问一答。

**语言与流程【已定】** 先写英文，再写中文；中文要按中文重新写，不是把英文的俏皮话翻过来（“Fair enough”不是“公平”）。中文读起来像中世纪西方奇幻的译本，不用古风词，不用网文腔。所有玩家看得到的文字都走本地化表，中英文一起改。玩家的名字写 `{name}`。

**旁白** 用第二人称“你”，写看得见、听得见的东西和动作。不替人物下判断，不故作暗示（“像是把什么事默默记下了”“你注意到了他没问”这类不要）。人物分不清的东西，旁白也只写他感觉到的（分不清是灯还是月光，就写“有光”）。

**主角的自言自语** 像真人累极了嘟囔出来的话：有喘息、叹气、语气词、说到一半的念头；多用带疑惑的自问，不下结论；不描述过程（不会说“越来越薄，然后就没了”）；不对不存在的人说话（不说“瞧”）；不一本正经地报出名称（说“这灌木”，不说“是黑刺李吧”）；紧张的时候不打量东西（摸到石头就是攥紧，不会掂量大小）。

**对白** 一句话要有主语和宾语，标点要对，问句用问号。人物只能说他知道的事，也只能照他站的位置说（村里人不会把邻里叫“那里的人”）。人和人之间用名字或称呼，不用“烧炭人”这样的职业泛称。不替对方做他还不知道前提的安排（不知道对方要不要留下，就不能说“他们会让你吃饱”）。每个人说话要合他的人设，写之前先看他的角色卡。主角例外：他的性子由玩家在选项里定，不由玩家选择的文字不能把他写死成害羞、冷淡或强势中的哪一种。

**两个男人之间的张力【已定】** 克制、细腻、有潜台词，可以有隐约的吸引，不刻意也不平淡。张力从哪里来要看是谁：信使的来自他**没有距离感而不自知**（握住手、凑近看、说出越界的实话，自己当没事），主角这边怎么回应由玩家选。无心的越界不是油腻，有意的撩才是。不要霸总腔、油腻调情、网文式的撩拨（“先欠着，早晚来讨”这类不要）。斗嘴和针锋相对只给人设本来如此的角色。每个角色的戏要同时对得上他角色卡里的两项：“吸引玩家的点”（这一场有没有兑现它）和“吸引的性癖人群”（有没有守住他的类型、没写成别的型）。这是两件事，见 [cast.md](cast.md)。

**选项** 动作选项不加括号（“把手抽回来。”），说话的选项带引号（“你先说。”）。选项只改变措辞，不改变后果；每个选项后面的话都要接得上主线下一句。

**卡牌文字** 卡名在卡面标题里放得下：中文约五个字以内，英文约九个字母以内。说明文字一两句，写这张卡在此刻对主角意味着什么，不讲设定。

**世界观上的禁忌** 白老妇不能显得虚弱；没有雪不是谜；种子没有坏处；主角的过去不说；传说就是传说，不另编真相。详见 [world.md](world.md)。

交稿前把整场戏按顺序用中文读一遍，站在听话的那个人的位置上逐句过：谁说的、对谁说、为什么是现在、什么情绪、听的人是什么感受。再专门找一遍上面这些毛病，包括用户没有标出来的句子。
