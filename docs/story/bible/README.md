# 设定集（现行版本）

这里是写文案时要对照的**现行设定**，每份文件只讲一件事，只写现在有效的内容。写或改任何台词、卡牌文字、旁白之前先读相关文件；写完或改完之后，凡是产生了新的事实、称呼、人物信息或写法规定，**同一次改动里就把它写回这里**，不能只改游戏文字。

| 文件 | 内容 |
|---|---|
| [world.md](world.md) | 世界观：帝国、白冬与白老妇、种子、哪里有雪 |
| [places.md](places.md) | 背风地、黑刺李林、溪边小道：已经写进游戏的细节 |
| [cast.md](cast.md) | 人物一览：每个人的人设、吸引玩家的点、吸引的性癖人群（这是两件事），和还没有人承担的标签 |
| [appeal-types.md](appeal-types.md) | 性癖类型参考表：给人物定“吸引的性癖人群”时逐个维度查 |
| [characters/hero.md](characters/hero.md) | 主角的角色卡 |
| [characters/messenger.md](characters/messenger.md) | 信使（奥辛）的角色卡 |
| [style.md](style.md) | 文风：旁白、独白、对白、恋爱张力、禁用写法 |
| [glossary.md](glossary.md) | 专名与称呼的中英对照和确认状态 |
| [continuity.md](continuity.md) | 剧情进行到哪、谁手里有什么、谁知道什么 |
| [open-questions.md](open-questions.md) | 还没定、需要用户拍板的事 |

每一条设定后面标了状态：**【已定】** 是用户明确说过的；**【暂定】** 是我为了写下去先定的，等用户确认，用户否了就改；**【未定】** 是还没有答案的，写到它之前必须先问用户，不能自己编。

新增人物时，在 `characters/` 下建一张卡，照现有两张的栏目填，填不出的栏目写【未定】，并在 `cast.md` 的表里加一行。每张卡必须有这些栏目：一句话人设、**吸引玩家的点**（这个人凭什么让玩家想和他相处）、**吸引的性癖人群**（照 appeal-types.md 的七个维度逐个写命中哪些、不命中哪些，不能只从用户举的例子里挑；和吸引点是两件事，定义见 cast.md；主角例外，他没有“不命中”）、名字、他是谁、知道什么和不知道什么、说话方式、到目前为止做了什么、和主角之间、美术、还没定的。人设、吸引点和性癖人群要在写他的第一句台词之前由用户定下或确认。用户每一次裁定的原话和日期按时间记在 `docs/knowledge/story-premise.md`，那里是来源；这里是整理后的结论，两处不一致时以较新的用户裁定为准，并立刻把这里改对。`docs/story/world-bible.md` 是 2026-10-03 的旧提案，大部分已被推翻，不要再当依据。
