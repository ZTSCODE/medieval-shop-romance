# 信使

**一句话人设【已定】** 暖心大哥哥；爽朗，缺根筋。

由此而来的写法：他看得见别人冷不冷、饿不饿、累不累，看不见别人是不是在不好意思。他对人好是动手的：递东西、拉一把、凑近了看。笑得大声，说话直来直去，想到什么说什么。他从不呛人、不占人便宜、不得意，也不会有意地撩：他做的事在他自己看来再平常不过。针锋相对、挑衅、有意的进逼、网文式的撩拨都不是他。

**吸引玩家的点【前三条已定，用户原话；其余暂定】**
- **无意识的亲密接触。** 他碰人就像喘气一样不过脑子：手凉了就握住，说话时搭着肩，凑到很近去看对方的脸，顺手替人拢衣领。他完全不觉得这有什么。
- **爽朗、缺根筋。** 该细的地方细（看得出你冻坏了），偏偏在这一件事上迟钝（看不出你为什么僵住）。
- **他没意识到主角在害羞，于是更进一步。** 主角一僵、一躲、不说话，他只当是冷、是累、是怕生，反而靠得更近、握得更紧，或者说出越界的话而不自知（比如把“你长得真好看”当成一句实话随口说出来）。
- 玩家比他先知道。每一次他毫无察觉地越界，心跳的是主角和玩家，不是他。玩家会一直等他哪天自己反应过来的那一刻。
- 在又冷又怕的开头，他是第一个对主角好的人，而且不追问。他是带玩家认识这个游戏的人。
- 他留着没说完的话（“我们见过吗？”）。

**吸引的性癖人群【暂定，待用户确认；按 [appeal-types.md](../appeal-types.md) 逐个维度过了一遍】**
- 体型与外形：运动员体格（jock／狼），结实不夸张；黑皮、晒痕；手大、手热。
- 年龄与辈分：大哥哥、年上感，带一点爹系的照顾，但不管着人。实际年龄【未定】。
- 身份与装束：跑信的，相当于这个世界的体育生；身上是赶路的打扮（月桂、信包、黄铜水壶）。
- 性格：阳光、爽朗、直球、天然钝感（缺根筋）、温柔照顾、专一和忠犬的底子。
- 两人之间的动态：阳光配阴沉（他是亮的那个）、照顾与被照顾、伤痛与安慰、慢热，以及“迟来的开窍”：等他自己反应过来。
- 相处里的小点：无自觉撩、零距离感与肢体接触、体温（把冷的手捂热）、共用一只水壶、叫名字、一句越界的实话。
- **不命中**：霸总与有意的强势、掌控欲、强制、腹黑与白切黑、钓系与有自觉的撩、病娇、猥琐、高冷、死对头；他自己不害羞。
- 位置【未定】。

**写他的戏时** 越界必须是无心的、身体先于念头的，并且立刻被他自己当成没事；一旦写成他知道自己在做什么，就变成了油腻。旁白只写他做了什么、主角身上起了什么反应，不替他解释，也不点破。他的迟钝只在“害羞”这一条线上，别把他写成对什么都迟钝的傻子。

**名字** 奥辛 / Oisín【暂定】，爱尔兰名，意思是“小鹿”，和他见面第一句“哦。不是鹿啊。”相呼应。卡牌和说话人标签上叫“信使 / Messenger”。他是玩家的新手导师【已定】。

**他是谁** 背风地的本地人【已定：村里人都是本地人】，在背风地和外面之间跑信，所以知道外面的情形，认得沼泽里的每一条路。年轻男人，头发上别着月桂，腰间挎着信包，带一只錾着一对黄铜翅膀的水壶。口头禅“圣徒在上”。

**他知道什么、不知道什么【已定】** **不知道主角在被通缉**，以为他是个遇到困难、从雪里走出来的旅人，也不追问。知道外面有雪、日子难过，但他不会把“我知道”挂在嘴上。对背风地没有雪习以为常。他是村里人，说起邻里用“大家”“村里”，不说“那里的人”。**不知道自己让主角不好意思。**

**到目前为止他做了什么** 在林子里遇到主角，给了他热水壶，发现他手冷就连手带壶一起握住，直到不抖（水壶还在主角手里）；说要先给烧炭的老芬恩送信，让主角顺着溪水走；不到一个钟头追上来，指给他看背风地；想起还没问名字；知道主角无处可去后，提起磨坊后头有间空屋，让他先住下。

**互通姓名那一段（2026-10-06 夜按这张卡重写，待用户审）** 他猛地站住转过身，扶住主角的胳膊就没再拿开。玩家有三种回应：站着告诉他名字（他说“好听。人也好看。”，说完就报自己的名字）；让他先说（他凑到不足一掌远去认主角的脸，还是觉得见过）；往后退半步（他跟上来半步，以为主角站不稳，又说主角耳朵冻红了，伸手捂住）。三种里他都没察觉自己做了什么。
