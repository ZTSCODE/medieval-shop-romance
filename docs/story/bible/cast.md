# 人物一览：吸引点与性癖人群（现行）

用户要求（2026-10-06）：每个角色都要想清楚两件事，而且**这是两件不同的事**，分开写、分开判断。

**吸引玩家的点**：这个具体的人凭什么让玩家想多看他、多和他相处。要写到具体的相处方式上，是只有他才有的东西，例如信使的“无意识的亲密接触”“没意识到对方害羞，反而更进一步”。不是“温柔”“可靠”这类放在谁身上都行的词。

**吸引的性癖人群**：他命中哪几类特定的口味，决定他属于哪一型。不能只从用户举过的例子里挑：照 [appeal-types.md](appeal-types.md) 的七个维度（体型外形、年龄辈分、身份装束、性格、两人之间的动态、相处里的小点、位置）逐个过一遍，写清命中哪些、不命中哪些。

两者不能互相代替：同一个标签可以由吸引点完全不同的两个人承担；一个吸引点也不等于任何一个标签。写台词时两样都要对照：这一场有没有兑现他的吸引点，有没有守住他的类型、没写成别的型。
