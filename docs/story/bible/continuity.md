# 剧情进度与前后衔接（现行）

台词全文在 `docs/story/opening-script-draft.md`（由游戏数据生成）。这里只记后面的文字必须接得上的事实。

**玩家已经看到的顺序** 开场动画（帝国的故事；结尾只说帝国看守的东西被拿走了、全国戒严）→ 取名 → 雪线边：主角一个人，桌上是“你”和种子卡 → 黑刺李林出现，他犹豫 → 新手目标 → 走进林子 → 信使和溪边小道出现 → 与信使相遇，说完信使先走 → 沿溪边小道走 → 信使追上来，背风地出现 → 第二场对话：问雪、别一个人进村、互通姓名、得知他无处可去、提起空屋 → 两人朝炊烟走去。**现有内容到这里为止，还没有进村。**

**此刻谁手里有什么** 主角带着种子（一直在桌上）；信使的黄铜水壶还在主角手里，没有还。

**此刻谁知道什么** 主角知道：信使叫奥辛，在背风地和外面之间送信；前面的村子叫背风地，那里没有雪，村里人怕帝国找来；磨坊后头有间空屋可以先住。信使知道：这个人是从雪里徒步走出来的，冻得厉害，没有要找的人，没有要去的地方。信使**不知道**：他被通缉、他带着什么、他从前是做什么的。主角的名字信使已经知道了（三个选项里主角都说了），后面的台词里信使可以叫 `{name}`。

**还没有回收的东西** 信使第一次见面问过“我们见过吗？”，互通姓名时如果玩家让他先说，他会再提一次“还是觉得在哪儿见过你”，然后自己认定没见过；这件事到底有没有下文仍未定；水壶；老芬恩的那封信；主角的过去；种子要怎么种。
