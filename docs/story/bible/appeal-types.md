# 性癖类型参考表（给人物定“吸引的性癖人群”时查）

用户要求（2026-10-06）：不能只从用户举的例子里挑，要自己把男同向受众的口味类型研究清楚、补全。下面是整理出来的词表，按维度分开；给一个角色定标签时，**每个维度都过一遍**，写清楚命中哪些、明确不命中哪些。它只管“类型”；这个人凭什么吸引玩家（钩子）是另一件事，见 [cast.md](cast.md)。本作不写裸体和床戏，所以这里只收人物类型、相处方式和点到为止的感官细节，不收具体行为；偏黑暗的几类（强制、鬼畜、病娇等）列在表里是为了知道它们存在，要不要做、做到什么程度由用户定。

**一、体型与外形**
- 圈内体型叫法：熊（壮硕、多有体毛）、小熊、肌肉熊；狼（精壮结实、成熟）；狒狒（匀称的普通体型）；猴（清瘦、线条明显）；猪（偏胖）。英文圈对应：bear、cub、muscle bear、wolf、otter（瘦而多毛）、twink（纤细少年感）、twunk（少年脸加肌肉，中文也叫金刚芭比）、jock（运动员体格）、gym bunny（健身练出来的大块头）、chub、daddy、rugged（粗粝的户外感）、clean-cut（干净利落）、geek（书卷气）。
- 具体的点：肌肉、薄肌、宽肩（双开门）、大块头、体毛、胡茬或络腮胡、黑皮或晒痕、伤疤、茧子和粗糙的手、手大、嗓音低、身高差、体型差、长发或束发、少白头、眼镜、纹身或烙印。

**二、年龄与辈分**
年上、年下、同龄；大叔；爹系（像长辈一样照顾和管着人）；大哥哥；奶狗（乖、黏人的弟弟）；狼狗（阳刚、忠诚、有攻击性的弟弟）；少年感；人夫感（稳重、会过日子）；养成（看着一个人长大）。

**三、身份与装束**（放到这个世界里的对应）
体育生与运动员（跑信的、摔跤的、伐木的）；军警与制服（帝国士兵、骑士、守卫）；护卫与保镖；糙汉与手艺人（铁匠、磨坊主、烧炭人、猎人）；书卷气与学者（书记官、抄写员、药师）；神职与禁欲感；贵族与上位者；流氓、不良、走私的；医者；覆面与面具（遮住脸的人）；异族或非人；落魄的前大人物。

**四、性格属性**
- 暖的一侧：温柔、照顾型、阳光、爽朗、忠犬、专一、直球（想什么说什么）、天然与钝感（缺根筋）、纯情、害羞、哭包、可爱。
- 冷的一侧：高冷、冷淡、高岭之花（只可远观）、禁欲系、寡言、阴郁、自卑、厌世。
- 带刺的一侧：傲娇（嘴硬心软、口嫌体正直）、毒舌、痞（流氓气）、钓系（会勾人）、诱（主动撩）、腹黑、白切黑（看着无害，其实有城府）、斯文败类。
- 强的一侧：强势、王道与霸总、掌控欲、占有欲强、护短。
- 重口的一侧：病娇、疯批、鬼畜、偏执、猥琐。
- 复合型：美强惨（好看、厉害、命苦）、反差萌（外表和内里相反）、外冷内热、外热内冷。

**五、两个人之间的动态**（关系桥段）
死对头变恋人、对手变恋人、朋友变恋人与竹马、破镜重圆、阳光配阴沉（grumpy/sunshine）、年龄差、身份差与主从、强强（两个都强）、被迫同处、只有一张床、假扮情侣、搭伙过日子、保护者与被保护者、秘密关系、禁忌之恋、慢热、双向暗恋、单箭头苦恋、伤痛与安慰（hurt/comfort）、照顾与被照顾、救赎、赎罪、追回来（做错事的一方实打实地弥补）、性向觉醒、家人感（一群人成了家）、牺牲感、恨海情天（爱恨都到极处）、强制与禁锢（黑暗向）、虐恋、养成。

**六、相处里的小点**（一场戏里可以兑现的东西）
无自觉撩（做的人不知道自己在撩）、有自觉撩、零距离感与肢体接触、渴望被碰（touch-starved）、克制到发抖、脸红与嘴硬被拆穿、吃醋、只对一个人温柔、叫名字与换称呼、被看穿、俯视与仰视、耳语、体温（手凉被捂热、身上有热气）、汗、包扎伤口、喂食与递水、共用一件东西（比如同一只水壶）、穿对方的衣服、背与抱、并肩走、同一个屋檐下、醉酒、睡着靠过来、一句越界的实话。

**七、位置**
攻、受、互攻（圈内也叫 1、0、0.5），以及强攻强受、美攻、壮受等组合。受众很看重这一条。本作不写床戏，但人物在关系里偏主动还是偏被动仍然会被读出来；每个角色要不要定、怎么定，由用户决定。主角的这一条交给玩家自己选。
