# 地点（现行）

**背风地 / the Lee【名字已定】** 一个普通的小村子，在帝国势力的边缘之外。村里人都是本地人，最多极个别外来的【已定】。这里没有雪，村里人不觉得稀奇【已定】。大家都怕帝国哪天找到这里，所以冷不丁见到生面孔会慌；信使因此叮嘱主角别一个人进村【已定】。已经写进游戏的细节：远看是炊烟和一片屋顶；村里有一座磨坊，磨坊后头有间空了两年的屋子，屋顶漏雨，门还结实，信使提议主角先住那儿【暂定，出自现行台词】。卡牌说明：“雪还没有到过这里。”

**黑刺李林 / Blackthorn Wood【暂定名】** 背风地外面的一片普通林子，没有魔法【已定：林子是普通的】。又湿又密，底下很黑，长满带刺的灌木。主角从雪地过来，看见它时犹豫要不要钻进去躲。里面地是软的，有雾。卡牌说明：“又湿又密，够黑，藏得住人。”

**溪边小道 / Brookside【暂定名】** 林子里沿着一条小溪的路，顺着走就到背风地。信使让主角“顺着溪水的方向走”。卡牌说明：“顺着水走，迟早走到有人的地方。”

**雪线** 主角是徒步从雪里走出来的。雪在林子外面一带越来越少，到这里没有了。

**林子里住着的人** 烧炭的老芬恩 / old Finn【暂定名】，信使要先给他送一封信。只出现过这一次名字，没有出场。
