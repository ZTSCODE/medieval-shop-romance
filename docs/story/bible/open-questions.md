# 还没定的事（需要用户拍板）

写到下面任何一条之前先问用户，不要自己定。定下来以后把它移到对应的文件里，从这里删掉。

**世界**
- 开场动画的旁白说粮车“从南方来”，而现在的设定是背风地在帝国势力的边缘、往南很多地方没有雪。帝国的本土在哪一边、背风地相对它在什么方位，需要说清楚，否则旁白和游戏里的说法会打架。
- “白老妇”这个中文名是否采用。
- 开场动画的旁白和后备的五页序幕还是旧说法（没有白老妇、没有种子），什么时候按新设定重写。

**主角**
- 一句话人设是否认可（现在写的是：带着罪、累到了头、对谁都提防的普通人）。
- 年龄、家乡；他打算拿种子做什么；他的过去什么时候、对谁说出来。
- 他见到没有雪的地面会发愣，是因为他这辈子只见过雪：这一点是我推出来的，是否成立。

**信使**
- 名字“奥辛 / Oisín”是否采用。
- 年龄、家人；他自己想要什么（和恋爱无关的）、他的底线；他是不是可攻略角色。
- 他第一次见面问“我们见过吗？”，是随口一问，还是以后要用的伏笔。

**吸引玩家的点、吸引的性癖人群**
- 信使的性癖人群是我照类型表逐个维度写的，需要用户确认或改写；他的“年上”是指相处的姿态还是实际年龄比主角大；他在关系里的位置定不定。
- 主角：固定的只有赎罪、神秘、被追捕，这样理解对不对；还有没有别的必须固定的。
- 互通姓名那一段已按“无意识的亲密接触”重写成三种不同的回应（站着说、让他先说、往后退），等用户审；“人也好看”“把你的耳朵捂住”这种程度的越界合不合适。
- 以后要不要加承担别的类型的角色，加哪些（空着的类型见 cast.md）。

**背风地**
- 村子的规模、有哪些人、谁说了算；主角进村以后由谁接待。
- 磨坊、空屋这些细节是我写台词时加的，是否保留。

**名字**
- 种子卡“老妇的种子 / Her Seed”；烧炭的“老芬恩 / old Finn”；黑刺李林的英文短名；游戏正式名称。
