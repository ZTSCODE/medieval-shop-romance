# 整纸样式与独立UI比例

版本范围（2026-10-07 核对）：本文保存 2026-09-22 的整纸接入及比例第一版记录，素材与测试结果属于当轮。现行比例由 `scripts/ui/ui_scale.gd` 的配置版本 2 定义：自动、60、75、90、100、110、120；120 的实际系数为 0.75，100 为 0.625，自动不超过 0.75。迁移与验收见 [比例第二版](knowledge/settings-popup-density-scale-v2-20260929.md)。下方旧选项和旧系数表只作历史，不能覆盖新版设置。

## 本轮方向

唯一图像参照是 `assets/art/ui/forest_rebuild/menu-title-plaque.png`。原始提示词来自同目录 `menu-manifest.json`；沿用原纸面的宽斜向笔触、自然薄边与炭褐色，只按窗口用途改外形比例、装饰和留白。不使用中间迭代图作生成输入。

新增素材统一放在 `assets/art/ui/title_family_20260922/`，完整提示词、源图路径、实际尺寸和透明度检查随素材存档。普通面板没有中间竖穿、上下露出的底纸带。原主菜单旅途题板保持原图。

设置与记录纸面没有花枝装饰，防止文字和内容压住图案；暂停、对白仅保留角部装饰。V1及带花枝的普通面板V2只归档，不作为当前窗口皮肤。

所有窗口共用 `paper_skin.gd`：从完整绘制的窗口纸面选对应比例，近似匹配时等比绘制；窗口因内容变宽增高时，对同一张源纸面分区等比取景，保留外边与完整角部。没有单独生成的边框、没有重复铺满内部的小纹理。小纸条继续使用原菜单按钮整纸图。所有文字仍由引擎实时绘制，插画和实际卡牌不改。

## 比例依据

- [Godot 多分辨率文档](https://docs.godotengine.org/en/stable/tutorials/rendering/multiple_resolutions.html)：画布布局与原生像素渲染分开，UI可提供独立比例控制。
- [FFXIV 官方HUD布局指南](https://na.finalfantasyxiv.com/uiguide/know/know-hud/hud-layout.html)：提供界面元素的独立尺寸调整。

本项目采用独立UI比例设置；78%是根据用户对4K过大的反馈选定的项目默认值，并非通用行业标准。保留原生3D渲染与棋盘尺度，不改全局Viewport，不额外乘Windows系统DPI。

| 游戏实际像素尺寸 | 自动UI系数 |
| --- | --- |
| 1920×1080及以下 | 100% |
| 2560×1440 | 约92.7% |
| 3840×2160 | 78% |

手动选项为75%、85%、100%、115%。相对于本项目原逻辑UI尺寸生效，修改立即重排并独立保存。原生下拉与确认窗同步处理。极小窗口仍保留滚动容器以访问全部设置。

实测主机为3840×2160、DPI144，Godot报告screen_scale=1.0，逻辑画布1600×900。没有修改系统150%缩放，也没有把问题归因于未经证实的双重DPI。
