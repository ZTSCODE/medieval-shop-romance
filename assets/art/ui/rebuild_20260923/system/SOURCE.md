# 系统菜单素材来源

本目录五件 PNG 分别调用内置 image_gen 独立生成，均要求透明背景；没有裁剪概念图。运行取景仅去除透明空白，不拼接纸边。

共同提示词：完整、正视、暗灰紫褐哑光纸，克制宽幅交错干笔，轻微手工起伏的平直边缘，微圆角，不切角，无大缺口、金属、木质斜面和投影。

- button：独立空白横纸条，略错位薄底纸，所有按钮状态复用同一 PNG。
- pause：适中竖向完整空白纸，用作暂停主体。
- panel：接近正方形完整空白纸，用作系统子页。
- wide：横向完整空白纸，用作宽弹窗。
- title：完整标题牌，左右植物印、上下细线，中间留字。

原生尺寸分别为 2172×724、1086×1448、1315×1196、1774×887、1983×793。生成器没有完全执行请求的4倍尺寸，因此不把插值放大记作原生高清。
