# 时间控制图标

采用内置 image_gen 分别生成三个独立透明 PNG。暂停图标为两条没有上下连线的竖杠；播放为单个三角；快进为两个三角。暂停尺寸 1287×1222，可见边界（401，356，485，511）；播放尺寸 1278×1230，可见边界（377，322，542，621）；快进尺寸 1536×1024，可见边界（341，271，875，490）。边界按 alpha > 16 统计。快进的透明 RGB 在部分预览中似光晕，但轮廓外所检查像素 alpha 为 0，不是可见光晕。

暂停提示词：一个极简暂停图标：两条分离的竖杠，绝不在上下连接，不能像罗马数字II。暖米灰手绘剪纸实心轮廓，小到20像素仍清楚。不要字、数字、背景、边框或阴影。透明背景。

播放提示词：一个极简播放图标：单个右指实心三角。暖米灰手绘剪纸轮廓，小到20像素仍清楚。不要字、数字、背景、边框或阴影。透明背景。

快进最终提示词：两个并排向右的实心三角，暖米灰色，极简手绘剪纸快进图标，中间有小空隙。只画平涂三角，无发光、无光晕、无阴影、无字、无边框。透明背景。
