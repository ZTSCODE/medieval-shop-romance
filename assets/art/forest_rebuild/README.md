## 提示词约束

各次生成共有约束：独立生产组件、无 UI 和文字、平涂厚薄有变化的哑光水粉笔触、宽阔色面、低饱和灰蓝绿/橄榄/褐色；避免写实 3D、光滑反光与黑描边。透明物件逐次明确要求 `Transparent background, 透明背景, actual alpha`，全物体入镜且有透明余量。

- 泥地：安静暖褐色实地，稀疏赭褐宽笔，俯视、均匀光照、四边连续，无物件、阴影与透视。
- 外围：深橄榄褐土、稀少落叶碎片、低反差宽笔，四边连续。
- 阔叶：不对称阔圆叶、深灰绿与灰蓝绿、少量橄榄叶、小蕨叶下层，无细草毯。
- 白花：灰橄榄分枝阔叶、小米白五瓣花与赭黄花心。
- 岩石：一大两小不规则低石、灰板岩明暗块面、少量橄榄和赭色苔藓。
- 大树：灰褐分叉树干、灰蓝绿/橄榄阔叶冠、整体略向右倾斜。
- 背包：旧锈褐布皮包、翻盖与赭黄小扣、底部绑卷毯、三分之四视角。
- 地图：展开旧羊皮纸、无文字、灰蓝河流与赭色路径、简化林山符号、底部斜放木铅笔。
- 木杯：厚壁矮杯、右侧杯柄、可见深色饮料、灰褐木纹宽笔。
- 灯：黑铁框、上方环柄和锥盖、烛焰与赭金暖光小窗，无巨大光晕。
- 远景：蓝灰夜空、窄淡云与右侧米白小月、逐层退远的柏树和阔叶剪影、右侧小石头村庄、拱桥与银蓝河流；下半部仅树林，无桌面卡牌。
- 独立村庄：小方塔、暗赤瓦顶、三点暖窗、四间低屋与前方拱桥；透明拱洞，无树木、河流、地块和天空。
- 森林卡插画：2:3 竖幅，浅暖灰曲折树干、灰蓝深冠、浅色弯曲林道、灰橄榄矮丛和米白野花，不透明满幅，无卡框和文字。
- 树卡插画：2:3 竖幅，单株分叉浅灰古树、蓝灰冠与暗橄榄群叶，根部白花和矮丛、后方安静灰蓝林地，不透明满幅。
- 镇口卡插画：2:3 竖幅，暖灰石拱入口、低方塔与暗陶红屋顶、浅色入口路、后方灰蓝树林和柏树，少量米白花，不透明满幅。

## 接入与限制

`TableMeadow3D` 世界坐标分块错位摆放阔叶、岩石、白花；保留横向自然风、完整扫动回弹和 0.35 秒冷却，岩石弯曲系数为零。图像运行时裁除透明余量并生成 mipmaps，再缓存，不修改原 PNG。前景树木与露营物件为独立 Sprite3D，无真实或假投影。远景由主棋盘画面层合成。

单件图像已逐张检查，透明采样通过；整体物件位置、光照、前后遮挡和 4K 外观须以集成后的实际截图验证，尚不能仅凭组件宣称完全还原。

## 首轮实机精修

检查 `work/forest-integrated/03-selected-cards-4k.png` 后发现旧版植被过密遮住木框，露营道具过小。已把每分块候选 16 降为 6、阔叶比例 78% 降至 46%、白花比例 13% 提至 36%；木框侧面留 145 逻辑像素、前方留 265 像素根点间距。灯笼、杯子、地图和前景背包约放大 1.5–2 倍。

`work/forest-environment-refine/03-selected-cards-4k.png` 为此次实际 3840×2160 截图；同轮原生流程 6 项通过、错误日志为空。仍存在均匀分布感，近景叶片相较参考可以更暗；这不是用户视觉定稿。

随后轻量修整：左右近景阔叶再放大 1.25 倍，亮度系数 0.65；分布使用固定种子的低频 Simplex 区域权重筛选候选，形成疏密变化，不逐帧改位置。`--headless --check-only` 对 `table_meadow_3d.gd` 检查退出 0、错误日志为空；此最后修整待主代理合并后的截图验收。

## 连续折面适配

用户否决屏幕叠层远景后，植被批绘、树木与道具均通过 `FoldedTerrain.world_position` 放置于真实折面。外围地面由主舞台统一构建，本模块不再生成额外四条平面。批绘包围盒根据映射后的根点重算；风场和拨动仍采用展开坐标，避免坡面投影改变交互半径。

在棋盘后缘外 4、9、16、26 米增加四层世界空间树团，23 米位置布置独立村庄。树团的最终近大远小来自真实 Camera3D 投影。此轮脚本检查见 `work/forest-environment-refine/fold-check.log` / `fold-check.err`，退出 0；不将脚本检查称为折面视觉验收。

后坡继续延展到 38、54、73、95、120 米五层散布树团，各层横向范围随距离增加，每团有树、阔叶与少量白花并留间隙。远坡植物合并为三个 MultiMesh，65 米处另有独立村庄。远坡根点始终为逻辑像素映射后的世界位置，未引入屏幕贴图摆放或每帧随机位移。

后续实机发现巨树遮住纵深，已把近后缘四层树降低并向通廊两侧留空，中轴由棋盘顶部逐渐转向右侧远处村庄；通廊内仅保留低矮稀疏白花。`work/folded-env-refine` 原生折面流程 6 项通过，截图可见城桥与远处林地。截图之后补四件低岩石/叶团承接城桥脚部，脚本检查通过；最远背景构图由主舞台继续验收。
